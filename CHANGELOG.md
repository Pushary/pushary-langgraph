# Changelog

## 0.4.0

**Customer reviews at LangGraph interrupts.**

Ask confirm, choice and text questions in the native Pushary app. Preserve trusted customer and review context across a native interrupt. Only an approved confirmation may route to a protected action.

The checkpointed recipe demonstrates delayed answers, verified callbacks and duplicate handling. The application owns checkpoint storage and business execution.

Requires the shared Pushary SDK 2.1. Finish existing pending operations on their original SDK version before upgrading. The adapter is MIT-licensed; real phone delivery uses the hosted Partner service.

[Run or adapt the example](https://github.com/Pushary/pushary-langgraph/blob/main/examples/README.md).
